# 工具提醒按钮 + 行分隔线（2026-09-27）

需求（哥哥）：工具箱面板每个工具条目上加一个按钮，点一下给模型发一条消息，
只提醒**这一个**工具可能有用；另外两个工具条目之间渲染一条虚线。

## 改了什么

| 文件 | 改动 |
|---|---|
| `src/switch-notice.js` | 新增 `toolReminderText(tool, description)` 与 `createToolReminder(tool, description)` |
| `src/route.js` | POST 新增第三种 form `{ sessionId, tool, remind: true }` → `agent.inject(createToolReminder(...))` |
| `src/client.js` | `renderRow` 加「提醒」按钮；CSS 加行间虚线 + 按钮样式 |
| `tests/switch-notice.test.mjs` | 新增 3 条（文案信息点、无描述、消息形状） |

## 契约（POST /api/tool-gateway 现在有三种 form）

```
{ sessionId, enabled }              → 工具箱总开关 + 通知
{ sessionId, tool, disabled }        → 单工具开关 + 通知
{ sessionId, tool, remind: true }    → 只发提醒通知，**不改任何状态**
```

`remind` 分支**必须排在 `tool` 那一支前面**：两个 form 都带 `tool` 字段，
先判 `remind` 才不会被当成一次开关请求（旧宿主会因 `disabled` 缺失报 400）。

## 界面

- 每行右侧一个「提醒」小按钮，默认半透明（`opacity:.45`），行 hover / 聚焦时变实；
  点过之后变绿并显示「已提醒」（纯界面记忆，宿主侧没有也不该有状态）。
- 行与行之间：`.dsh-tool-gateway-panel-row + .dsh-tool-gateway-panel-row` 的 `border-top:1px dashed`。

## 提醒消息说什么

正文钉住四个信息点（测试按点断言，不整段相等）：

1. 是**用户**点的这个工具的「提醒」；
2. **不是开关变化** —— 工具一直是可用的（否则模型会以为出了变故）；
3. 这个工具的用途（宿主目录里的 description）；
4. 出口：对得上就用（`find_tools` 查参数 → `call_tool` 调），**确实用不上就说为什么**，
   别为了回应提醒硬凑一次调用。

## 生效方式（重要）

- **客户端半部**（`lib/client.js`）：刷新页面即可。
- **宿主半部**（`lib/route.js`、`lib/switch-notice.js`）：**必须重启 DSH**。
  profile 里那一行自己写着「host 侧静态插件没有 HMR —— 改完 lib/ 必须重启，光 bump revision 不够」。
  没重启时点「提醒」会拿到 400（旧路由要求 `disabled` 是布尔值）。
